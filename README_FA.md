# سلف‌بات (Self-Bot) — دستیار شخصی تو در گروه‌ها

یک **یوزربات** که با خود اکانت تلگرامِ تو کار می‌کنه (نه یک ربات معمولی)، پس مثل خودت تو گروه‌ها پیام می‌فرسته، روی دکمه‌ی ربات‌های بازی (مثل میو بات) کلیک می‌کنه و با **زمان‌بندی** کار می‌کنه.
کانکشن دائمی MTProto داره (بدون وبهوک)، پس جواب‌دادنش در حد میلی‌ثانیه‌ست.

## امکانات
- ⏱ **زمان‌بندی:** «هر ۵ دقیقه، تا ۵ ساعت، این پیام رو بفرست» — یا تا تعداد مشخص، با چند متن (ترتیبی/تصادفی)، با شروع با تأخیر و تأخیر تصادفی اختیاری.
- 🎮 **ربات‌های بازی:** ارسال دستور به ربات (`.bot`)، کلیک روی دکمه‌ها (`.tap`) و **کلیک خودکار زمان‌بندی‌شده** (`.click`) — مثلاً هر ۵ دقیقه «میو».
- 🎛 **پنل دکمه‌ای** (ربات جدا با BotFather): ساخت کار با ویزارد (انتخاب گروه از لیست گروه‌های اکانت)، توقف/ادامه/اجرا/حذف، آمار و رویدادها.
- 👑 **فقط تو مالکی؛** هر کسی رو بخوای ادمین کن (`.admin add`). ادمین‌ها کار می‌سازن ولی مدیریت ادمین/ورود/خروج/پاک‌سازی فقط مالکه.
- 🗣 پاسخ خودکار (trigger) با cooldown، `.send`، `.join`، `.leave`، `.purge`، `.id`، `.stats`، `.log`.
- 💾 کارها در Supabase ذخیره می‌شن؛ بعد از ریستارت ادامه می‌دن (بدون ارسال یک‌جای پیام‌های از دست‌رفته).
- 🛡 محافظ اکانت: حداقل فاصله، سقف تعداد کار، فاصله بین ارسال‌ها، مدیریت FloodWait (صبر و ادامه خودکار)، توقف و اطلاع‌رسانی در خطاهای جدی.
- ⏰ **تأخیر تصادفی فقط به عقب:** برای ربات‌های بازیِ کول‌داون‌دار هیچ‌وقت «زودتر از موعد» نمی‌فرسته (+۲ ثانیه حاشیه امنیت).

## دستورات (در هر چت، با پیشوند «.»)
| دستور | کار |
|---|---|
| `.every 5m for 5h : میو` | هر ۵ دقیقه تا ۵ ساعت در همین چت |
| `.every 5m for 5h to @group : میو \|\| سلام` | گروه دلخواه + چند متن |
| `.every 10m x20 jitter 10 random after 1m : ...` | ۲۰ بار، تأخیر تصادفی تا ۱۰٪، تصادفی، شروع بعد ۱ دقیقه |
| `.click every=5m for=5h bot=@MeowBot btn="میو"` | کلیک خودکار روی دکمه ربات |
| `.jobs` `.info 3` `.pause 3\|all` `.resume 3\|all` `.rm 3\|all` `.run 3` | مدیریت کارها |
| `.bot @Bot : /start` / `.tap @Bot متن‌دکمه` / `.send @chat : متن` | ابزار |
| `.trigger add * کلمه : پاسخ` / `list` / `rm 2` | پاسخ خودکار |
| `.admin add 123456789` (یا ریپلای) / `rm` / `list` | فقط مالک |

واحد زمان: `30s` `5m` `2h` `1d` یا `۵دقیقه` `۲ساعت`. دستورها را می‌تونی در «Saved Messages» اکانت هم بنویسی (کنسول خصوصی).

## راه‌اندازی (قدم‌به‌قدم)
1. **API_ID و API_HASH:** در https://my.telegram.org ← API development tools.
2. **SESSION_STRING:** روی کامپیوتر خودت (نه Render) `pip install telethon` و `python gen_session.py`؛ شماره، کد و رمز دومرحله‌ای رو بزن. خروجی رو مخفی نگه دار (دسترسی کامل به اکانته).
3. **ربات پنل (اختیاری ولی پیشنهادی):** از BotFather یک ربات بساز و `BOT_TOKEN` رو بردار؛ بعد داخلش `/start` بزن.
4. **دیتابیس:** `selfbot_schema.sql` رو در Supabase SQL Editor اجرا کن (با جدول‌های FitBot تداخل نداره).
5. **Render:** مخزن رو وصل کن (`render.yaml` آماده‌ست) و متغیرهای زیر رو بذار:
   `API_ID` `API_HASH` `SESSION_STRING` `BOT_TOKEN` `OWNER_ID` (آیدی عددی اکانت اصلی‌ات، اگه اکانت سلف جداست) `SUPABASE_URL` `SUPABASE_SERVICE_ROLE_KEY` `PUBLIC_BASE_URL`.
6. بعد از دیپلوی، پیام «🟢 سلف‌بات روشن شد» میاد. در پنل `/start` یا در تلگرام `.help` بزن.

## نکات مهم و صادقانه
- ⚠️ **ریسک اکانت:** تلگرام اتوماسیون روی اکانت شخصی رو دوست نداره. ارسال تکراری زیاد یا گزارش اسپم می‌تونه اکانت رو **محدود یا بن** کنه. با یک **اکانت جدا** تست کن، فاصله‌ها رو منطقی نگه دار و در گروه‌هایی که اجازه می‌دن استفاده کن. من مسئولیت بن شدن رو نمی‌تونم بپذیرم.
- 🔑 **SESSION_STRING = کلید کل اکانت.** هیچ‌جا غیر از Environment رندر نذارش. اگه لو رفت: تلگرام ← Settings ← Devices ← نشست رو ببند.
- 🚫 **یک نمونه فقط:** اگه همزمان دو جا (مثلاً لوکال و Render) با یک session اجرا بشه، تلگرام session رو باطل می‌کنه. به همین دلیل `healthCheckPath` عمداً در `render.yaml` نیست (جلوی دیپلوی هم‌پوشان رو می‌گیره) و ۲۰ ثانیه صبر قبل از اتصال هست.
- 😴 **بیدار ماندن در Render Free:** پلن رایگان بعد از ۱۵ دقیقه بی‌ترافیکی می‌خوابه و سلف‌بات هم متوقف می‌شه. ربات خودش هر ۴ دقیقه خودش رو پینگ می‌کنه و **توصیه می‌کنم یک مانیتور خارجی** (مثل UptimeRobot، هر ۵ دقیقه روی `PUBLIC_BASE_URL/health`) هم بذاری؛ ولی تضمینی نیست. برای کار ۲۴ ساعته‌ی مطمئن (مثل ۵ ساعت پشت‌سرهم) پلن Starter رندر رو بگیر.
- 🎮 منطق اختصاصی هر بازی رو نمی‌دونم؛ ربات فقط «پیام بفرست» و «روی دکمه کلیک کن» رو انجام می‌ده. دکمه‌ها رو با `.bot` ببین و متنشون رو به `btn=` بده.

## تست
`python tests/run_tests.py` — تست آفلاین موتور زمان‌بندی، دستورها، دسترسی‌ها، ویزارد پنل و منطق کلیک (با Telethon شبیه‌سازی‌شده).
